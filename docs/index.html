Features

Everything you need to manage logging agents

A complete control plane for distributed Fluent Bit and Fluentd deployments at any scale.

🗺️

Infrastructure Topology

Organize nodes into data centers, regions, and clusters. Auto-assign new agents via hostname glob, IP CIDR, or label rules.

📄

Configuration Management

Template-based configs with versioning, reusable modules, live rendering preview, lint, replay, and compatibility checks.

🚀

Remote Deployment

Push configurations to individual nodes, entire clusters, regions, or data centers in a single operation.

📊

Real-time Monitoring

Agent heartbeat tracking, metrics collection, runtime drift detection, health graphs, and optimization recommendations.

🔀

Log Pipeline Visualization

Interactive graph-based view of the full forwarding topology — from log sources through aggregators to outputs.

🤖

AI-assisted Analysis

Log sample analysis, config generation, and recommendations powered by configurable LLM providers (OpenAI, Gemini, and more).

🔐

RBAC & Scoping

Fine-grained role-based permissions with topology-level scope control at the data center, region, or cluster level.

🔑

Multi-auth

Supports local accounts, LDAP directory integration, and SAML 2.0 single sign-on out of the box.

⚙️

Agent Policies

Layered override policies (global → environment → cluster → label selector) for agent runtime settings without touching node configs.

Architecture

Three-tier design

Vue 3 SPA talks to a Go/Gin REST API which delivers config and commands to lightweight agent clients running on each node.

┌──────────────┐     ┌─────────────────────────────────────────────┐
│  Vue 3 SPA   │────▶│  Go Server (Gin)                            │
│  TypeScript  │     │  ├── Auth (JWT / LDAP / SAML)               │
│  ECharts     │     │  ├── Handlers  (REST API, HTTP only)        │
└──────────────┘     │  ├── Services  (business logic, interfaces) │
                     │  ├── Middleware (RBAC + Scope + Audit)      │
                     │  └── Models    (GORM: SQLite/MySQL/Postgres)│
                     └─────────────────┬───────────────────────────┘
                                       │ Agent API (heartbeat / config / commands)
                     ┌─────────────────▼───────────────────────────┐
                     │  Agent Client  (deployed on every node)     │
                     │  ├── Heartbeat + Metrics collection         │
                     │  ├── Config sync + hot-reload               │
                     │  ├── Remote command execution               │
                     │  └── Log shipping                           │
                     └─────────────────────────────────────────────┘
Topology Hierarchy:

  DataCenter  →  Region  →  Cluster  →  Node
                              ├── Environment  (prod / staging / dev / test)
                              ├── MatchRules   (auto-assign new agents)
                              └── Config       (inherited by all nodes)

Deployment

Three ways to deploy

Choose the deployment mode that fits your environment — from a single binary to Docker.

📦 All-in-One Binary

Frontend embedded in the binary. Copy and run — no separate web server needed.

# Build make build-all-in-one # Run cp config.yaml.example config.yaml ./fluent-manager-server

🔀 Separated (API + Static)

Backend serves the API; frontend is a static build behind Nginx or Caddy.

# Backend make build-server-linux # Frontend make frontend-package tar -xzf bin/frontend.tar.gz \ -C /usr/share/nginx/html

🐳 Docker

Build and run a container image. Includes the frontend. Mount your config file.

docker build \ -t fluent-manager . docker run -p 8080:8080 \ -v ./config.yaml:/app/config.yaml \ fluent-manager

Quick Start

Up and running in minutes

Default admin credentials: admin / admin123

1

Start the server

Use the all-in-one binary, Docker, or build from source. Copy config.yaml.example and edit as needed.

2

Open the web UI

Navigate to http://localhost:8080. The setup wizard will walk you through initial database, admin account, and auth configuration.

3

Build your topology

Create data centers → regions → clusters. Add match rules so new agents are automatically placed in the right cluster.

4

Deploy agents to nodes

Install the lightweight agent binary on each managed node. Only server_url and api_key are required — everything else is delivered by the server.

5

Create templates and push configs

Write config templates with modules, preview rendering, lint, then deploy to nodes, clusters, or entire regions in one click.
